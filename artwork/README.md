# Cassinux Artwork

This directory contains artwork created for the Cassinux Linux distribution.

## Contents

- `logos/` — Cassinux logos and branding
- `wallpapers/` — Cassinux desktop wallpapers
- `icons/` — Cassinux icons and graphical assets
- `themes/` — Cassinux visual theme assets

## Usage

These artwork files are intended for use in Cassinux and its official project materials.

Contributors may improve or add artwork through pull requests.

## Status

Cassinux is currently in alpha development, so artwork and branding may change in future releases.
